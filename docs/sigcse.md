# 🚦 Two Probabilistic Systems Walk into a Classroom

**The working example of the SIGCSE TS 2027 lightning talk.**

*Teaching Humans and AI Agents to Build Predictable Software, Together.*

A human and an AI agent both make mistakes. A check that runs does not. The
example on this page lets you walk the loop of the talk yourself: a check
fails, an agent helps diagnose, **you** change the application, the check
turns green. In the browser, nothing to install.
