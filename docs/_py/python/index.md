# 🐍 Welcome to Python

A tutor that never writes your program, a place to run yours, and one page
per assignment. Nothing to install, no account to create: the page runs in
your browser, and the tutor runs on a key you hold.

How it works, every week:

1. Open the week's page from Canvas.
2. Connect your engine key once (🔑 on the tutor — the free Groq key will do).
3. Write your program in the editor, run it, ask the tutor when you are stuck.
   It answers with directions — where to look, what to try — never with the
   answer.
4. Submit in Canvas, as the assignment says.
