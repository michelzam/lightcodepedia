# 🛢️ Welcome to Databases

INFOST 410 — Database Information Retrieval Systems.

The world runs on data, quietly behind the scenes — hospitals, factories,
schools, the shop that sells your pizza 🍕. This course teaches you how
that data is stored, retrieved, and kept reliable at scale: relational
databases and SQL first, then a look at the NoSQL families.
