# 🖼 A page that declares its own frame

[frame](#)
{: .frame reel="1" up="0" }

This page carries its frame on itself: it opens as a **reel** and cannot be
walked out of (`up="0"`) — whatever generic door brought you here. An explicit
URL flag still wins: open it with `?reel=0` and it reads as a plain page.

## 1 · The declaration

One IAL line near the top of the page. The flags merge into the address, so
every in-frame hop carries them forward.

## 2 · The precedence

The host's URL is the law; the declaration only fills what the URL left
unsaid.

## 3 · The payoff

Canvas and the invitations keep one generic short link, while each module
declares its own personality in its own file.
